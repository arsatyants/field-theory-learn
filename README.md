# Теория поля: интерактивный курс

Интерактивный курс по векторному анализу: градиент, дивергенция, ротор, поток поля, теорема Остроградского-Гаусса и теорема Стокса. Каждая тема с математическими формулами (MathJax) и живыми примерами на Rust в браузере.

## Структура

| Модуль | Тема | Файл |
|--------|------|------|
| 01 | Градиент | `01_gradient.html` |
| 02 | Дивергенция | `02_divergence.html` |
| 03 | Ротор | `03_curl.html` |
| 04 | Поток поля | `04_flux.html` |
| 05 | Теорема Остроградского-Гаусса | `05_gauss.html` |
| 06 | Теорема Стокса | `06_stokes.html` |

## Локальный запуск

Откройте `index.html` в браузере. Для Rust-примеров требуется интернет (Rust Playground API).

## Локальное выполнение Rust

```bash
cd rust-src
cargo run -- all      # все модули
cargo run -- 01       # только градиент
```
